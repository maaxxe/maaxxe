## Main AI projects

### PlankEye

Computer vision system designed to detect the corners of wooden planks for robotic applications.

The project includes:

- custom neural network architectures
- multi-object detection
- four-corner regression
- MobileNetV3 backbone
- BiFPN feature fusion
- GPU training with PyTorch
- dataset generation and augmentation
- model evaluation and KPI analysis
- integration into an industrial graphical interface
- vision-to-robot coordinate processing

---

### PlankEye GAN

Generative AI pipeline developed to generate synthetic training images for PlankEye.

Main objectives:

- increase dataset diversity
- generate realistic plank configurations
- control the number and position of objects
- preserve geometric consistency
- improve robustness of downstream vision models

Technologies include:

`GAN` · `PyTorch` · `PaddlePaddle` · `OpenCV` · `CUDA`

---

### GeoNet

Deep learning architecture for geometric object understanding and segmentation.

The project explores:

- semantic segmentation
- object center estimation
- geometric feature extraction
- EfficientNetV2
- U-Net architectures
- multi-task learning
- GPU distributed training
